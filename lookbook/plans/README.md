# 기획안 (plans)

클라우드 예약 작업이 매주 작성하고, PC의 `run.py`가 읽어서 처리한다. 주차별 폴더(`2026-W44/`)에 릴스 1개당 JSON 1개.

## 업로드 주기 (2026-10 조사 기준)

**주 4회**로 시작한다.

| 요일 | 시각 (KST) | 성격 |
|---|---|---|
| 월 | 20:00 | 계절·날씨 전환형 (예: "추워질 때 꺼내는 아우터") |
| 화 | 20:00 | 상황형 (하객, 출근, 데이트, 여행) |
| 목 | 20:00 | 체형·아이템 공식형 (예: "배럴진 코디 공식") |
| 일 | 21:00 | 다음 주 준비형 (예: "일주일 출근룩", 다가오는 행사) |

근거
- Buffer 분석(10.2만 계정, 210만 게시물): 주 1~2회에서 **3~5회로 늘릴 때 효과가 가장 크게** 오르고, 그 이상은 증가 폭이 줄어든다.
- 릴스 전용 가이드는 주 3~7회를 권장한다. 인스타 공식 권장 횟수는 없다.
- 대부분의 조사에서 평일 반응이 주말보다 높다. 한국·패션 계정 기준 시간대 자료는 찾지 못했으므로, 저녁 8~9시로 시작해 클릭 추적 데이터로 조정한다.

조정 규칙
- 4주 운영 후 릴스당 링크 클릭과 저장 수가 유지되면 주 5~7회로 늘린다.
- 품질(생성 이미지 완성도, 상품 매칭 정확도)이 떨어지면 횟수를 줄인다.

## 기획 작성 규칙

- 표지 `title`과 `sub`는 각각 **한 줄 12자 안팎**
- 후킹은 **상황·가격·계절·체형** 중 2개 이상 조합
- 한 주 안에 같은 패턴(예: 체형형)이 겹치지 않게
- `rationale.sources`에 실제로 확인한 출처 URL을 넣는다. 확인 못 한 수치는 쓰지 않는다

## 주요 필드

| 필드 | 설명 |
|---|---|
| `id`, `publish_at` | 고유 ID, 게시 시각 (한국 시간) |
| `hook.title` / `sub` / `badge` | 표지 문구. 한 줄 12자 안팎을 권장 |
| `rationale` | 이 주제를 고른 근거와 출처. 검수할 때 확인용 |
| `style` | 전체 룩에 공통으로 붙는 구도, 장소, 분위기 (ComfyUI 프롬프트에 합쳐짐) |
| `looks[].prompt` | 룩별 생성 프롬프트 |
| `looks[].label` | (선택) 큰 제목. 없으면 `Look N` (예: 요일 구성일 때 `MON`) |
| `looks[].overlay` | 영상에 들어갈 Look 자막 |
| `looks[].items[]` | 상품 매칭용 아이템 설명. `keywords`로 쿠팡 검색, `price_max` 이하로 필터 |
| `caption`, `hashtags`, `dm_keyword` | 인스타 캡션, 해시태그, 댓글→DM 키워드 |

광고 표기와 "AI 생성 · 비슷한 상품" 문구는 기획안에 쓰지 않는다. PC 쪽 파이프라인이 자동으로 붙인다.
